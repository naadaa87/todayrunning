# 오늘러닝

러닝크루와 러너가 코스를 짜고, 모임을 열고, 출석을 확인하고, 함께 안전하게 달린 기록을 남기는 과정을 한곳에서 처리하는 러닝 플랫폼입니다. 달리기 전후에 들르는 러너 프렌들리 매장까지 이어 줍니다.

이 저장소는 「오늘러닝 러닝 플랫폼 종합기획서 v2.2」를 바탕으로 만든 **홈페이지 시범 화면**입니다. 서버 없이 HTML·CSS·자바스크립트만으로 동작하고, 빌드 과정 없이 그대로 올리면 됩니다.

- 크루·모임·매장·대회 정보는 **예시 데이터**입니다.
- 로그인, 모임 신청, 기록, 코스, 안전 설정 같은 입력 내용은 **방문한 사람의 브라우저에만** 저장됩니다(서버 전송 없음).
- 날씨·대기질은 Open-Meteo에서 실제 값을 불러오고, 지도는 OpenStreetMap을 씁니다.

## 바로 열어 보기

### GitHub Pages로 공개하기(가장 쉬움)
1. 이 저장소 화면에서 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/(root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://naadaa87.github.io/todayrunning/` 에서 열립니다.

### Cloudflare Pages로 공개하기
1. Cloudflare 대시보드에서 **Workers & Pages → 만들기 → Pages → Git에 연결**을 누르고 이 저장소를 고릅니다.
2. 빌드 설정은 이렇게 둡니다.
   - Framework preset: `None`
   - Build command: 비워 두기(또는 `exit 0`)
   - Build output directory: `/`
3. **저장 및 배포**를 누르면 `*.pages.dev` 주소가 생깁니다. 이후 `main`에 반영할 때마다 자동으로 다시 배포됩니다.

> GPS 기록, 나침반, 화면 켜 두기, 카메라 스캔은 보안 주소(https)에서만 동작합니다. 위 두 방법은 모두 https로 열립니다.

## 둘러보기 좋은 순서

1. **홈**에서 지역을 바꿔 오늘의 달리기 조건을 봅니다.
2. **모임 찾기 → 모임 상세**에서 원칙 확인 후 신청합니다(닉네임만 정하면 됩니다).
3. **크루 관리 콘솔 → 출석·귀환 확인**에 뜬 6자리 숫자를 모임 상세의 ‘출석하기’에 넣어 봅니다.
4. **달리기**에서 컴퓨터라면 ‘체험 모드’로 기록을 만들고 저장합니다.
5. **오늘의 러닝 인증 카드**에서 매장을 고르고, **파트너 센터 → 인증 확인**과 비교해 봅니다.

## 폴더 구조

```
index.html … about.html   각 화면(머리글·바닥글은 core.js가 그려 줍니다)
assets/css/style.css      공통 디자인(흰 바탕 + 포인트 색 #E8452C)
assets/js/data.js         예시 데이터(크루·모임·코스·매장·대회)
assets/js/core.js         공통 기능(저장, 서식, 날씨 기준, 지도, QR, 로그인, 머리글·바닥글)
assets/js/pages/*.js      화면별 기능
assets/vendor/            Leaflet(지도), qrcode-generator(QR) — 오픈소스, 각 라이선스 포함
assets/img/               로고, 앱 아이콘, 공유 이미지
manifest.webmanifest      홈 화면에 추가(웹 앱)
```

## 정식 서비스로 갈 때 바꿀 것

- `data.js`의 예시 데이터를 서버 API로 바꾸고, 브라우저 저장(localStorage)을 계정 저장으로 옮깁니다.
- 귀가 공유를 실시간 위치 서버로 바꾸고, 도착 자동 확인과 지연 알림을 붙입니다.
- 인증 카드의 코드 검증을 서버에서 합니다(지금은 시범용 계산 방식).
- 위치정보·개인정보 관련 법률 검토 결과를 반영합니다(기획서 13.3).
