# 오늘러닝 홈페이지 구성

「오늘러닝 러닝 플랫폼 종합기획서 v2.2」의 정보 구조(6.2)와 기능 목록(5장)을 웹 시범 화면으로 옮긴 기록입니다. 시범 화면이 다루는 범위와, 앱·서버가 생겨야 완성되는 부분을 나눠 적었습니다.

## 1. 디자인 기준

| 항목 | 기준 |
|---|---|
| 바탕 | 흰색, 면 구분은 옅은 회색(#F5F6F8) |
| 포인트 색 | 육상 트랙의 붉은 주황 #E8452C(진하게 #B8331C, 옅게 #FDEDE9) |
| 글자 | 먹색 #1F2328, 본문 #3A3F45, 보조 #6B7280 |
| 상태 색 | 좋음 #1E8E5A, 주의 #B26A00, 경고 #C62828 — 날씨 기준과 보관 상태에만 씀 |
| 글꼴 | Pretendard(없으면 Noto Sans KR·시스템 글꼴) |
| 말투 | 밝고 담백하게, ‘~해요’체. 과장된 동기부여 문구 대신 구체적인 안내 |
| 반응형 | 920px 아래에서는 상단 메뉴 대신 하단 탭(홈·모임·달리기·기록·마이)과 전체 메뉴 |

## 2. 사이트맵

```
홈
├─ 모임 ─ 모임 찾기(목록·지도) ─ 모임 상세·신청 ─ 모임 만들기
├─ 크루 ─ 크루 찾기 ─ 크루 페이지 ─ 크루 관리 콘솔
├─ 코스 ─ 코스 찾기 ─ 코스 상세 ─ 코스 짜기
├─ 러너 매장 ─ 매장 찾기 ─ 매장 상세 ─ 오늘의 러닝 인증 카드
│            └─ 매장 입점 안내 ─ 매장 파트너 센터
├─ 러닝 도구(11종) ─ 달리기(GPS·귀가 공유·SOS) ─ 귀가 공유 받는 화면
├─ 대회
├─ 가이드
├─ 마이페이지
└─ 서비스 소개·개인정보 처리 안내
```

## 3. 기획서 기능과 화면 대응

시범 화면에서 동작하는 기능만 적었습니다. 괄호는 기획서 기능 번호입니다.

### 모임·크루
- 모임 찾기(B-07): 지역, 장소, 언제, 페이스, 거리, 입문 환영, 게스트 가능, 자리 있음, 검색어. 목록과 지도 보기.
- 모임 상세(B-02, B-04, B-10, B-11, B-12): 코스 지도와 시설, 운영진 안내와 장소 규칙, 페이스 그룹 정원, 원칙 확인 후 신청·대기, 날씨 기준, 공유, 캘린더(.ics) 추가.
- 출석(D-01): 운영진 콘솔의 QR과 6자리 숫자는 30초마다 바뀝니다. 참가자는 QR을 찍거나 숫자를 넣어 출석합니다. 같은 계산 방식이라 다른 기기에서도 맞춰 볼 수 있습니다.
- 모임 만들기(B-01, B-03, B-05, B-06): 반복 요일, 페이스 그룹 편집, 5명 넘는 그룹은 소그룹 분할 안내, 30명 넘으면 소그룹 필수 안내, 코스 장소 규칙 경고, 3일 안 일정은 날씨 미리 보기.
- 크루 관리 콘솔(C-02~06, C-10, D-02~05, G-02): 다가오는 모임별 날씨 단계, 결정 기록(그대로 진행·시간 앞당기기·거리 줄이기·실내 대체·취소), 출석→출발 확정→귀환 확인, 멤버 역할, 명단 붙여넣기, 공지·투표, 회비 기록(돈은 거치지 않음), 리포트 CSV.

### 코스
- 코스 찾기(A-04, A-05, A-10): 지역·형태·거리·야간 조명·보관함 필터, 지도에 경로 표시.
- 코스 상세(A-02, A-03, A-06): 시설 레이어, 장소 규칙, 예상 시간, GPX 내보내기, 이 코스로 모임 열기.
- 코스 짜기(A-01, H-08): 지도 클릭으로 지점 추가, 끌어 옮기기, 마우스 오른쪽 클릭으로 지점 삭제, 순환으로 닫기, 왕복 만들기, GPX 가져오기·내보내기, 가까운 장소의 시설 수와 규칙 안내.

### 러닝 도구·달리기·안전
- 도구(E-01, E-05, E-06, E-07, E-08, E-09, E-13~16, E-20): 스톱워치·랩, 인터벌(소리·진동·음성), 페이스 계산기, 기록 예측(리겔 공식), 페이스 밴드(인쇄), 심박 구간(여유 심박), 속도·트레드밀 환산, 메트로놈, 나침반, 속도계, 날씨. ☆로 도구함(L-02) 담기.
- 달리기(E-02~04, H-01): GPS 기록, 정확도 낮은 점·순간 튐 걸러 내기, 1km 구간 음성 안내, 화면 켜 두기, 저장 후 인증 카드 안내, 기록 직접 입력(수기 표시), GPS 없는 기기를 위한 체험 모드.
- 귀가 공유(F-04~07): 받는 사람·도착 예정 시간 선택 → 문자나 공유로 링크 전송, 위치 다시 보내기, 도착 알리기, 자동 종료 시간, 집 주변에서는 대략적 위치만.
- SOS(G-04, G-09): 119·112 전화, 비상 연락처에 위치 문자, 응급 정보 표시.
- 날씨·대기 기준(G-01): 기획서 부록 B의 가안을 그대로 코드로 옮겼습니다(core.js `TR.weather.stage`).

### 러너 프렌들리 매장
- 러너용(S-01~07, S-10, S-11): 지금 보관 가능·영업 중·샤워 필터, 내 주변 정렬, 매장 상세, 짐 보관 예약(보관표 번호), 소식 받기, 후기, 길찾기(카카오맵 링크), 인증 카드, 혜택 지갑.
- 노출 순서: 거리 → 영업 여부 → 보관 가능 → 평점. 돈으로 바꾸는 순서는 없습니다.
- 매장용(P-01, P-02, P-06~11, P-13~18, P-20, P-22): 입점 신청과 기준 점검, 오늘 현황, 한 번에 바꾸는 보관 상태(보관 가능·만석·잠시 중단), 인증 스캔(카메라 지원 기기는 바로 스캔, 아니면 기본 카메라로 QR을 찍으면 결과 화면이 열림), 혜택·영업 정보 편집, 예약 처리, 소식 올리기, 안내판 인쇄, 크루 제휴 제안, 후기 답글, 방문 리포트. 바꾼 내용은 매장 찾기·상세에 바로 반영됩니다.

### 마이페이지(L-01~L-12)
내 홈(이번 주·이번 달 거리, 다음 모임, 도구함, 날씨), 내 모임(신청·개설), 내 크루, 내 코스, 내 기록(주간 그래프, 최고 기록, CSV 내보내기, GPX 가져오기), 러닝화(I-07), 안전 설정, 기기 연결 일정, 알림, 계정(프로필, 홈 화면에 추가, 데이터 내려받기·삭제).

## 4. 시범 화면의 한계와 정식 서비스에서 할 일

| 시범 화면 | 정식 서비스 |
|---|---|
| 예시 데이터(`data.js`) | 서버 API, 실제 크루·매장 입점 |
| 브라우저 저장(localStorage) | 계정 로그인(카카오·네이버·애플·이메일), 기기 간 동기화 |
| 귀가 공유는 링크를 만든 순간의 위치 | 실시간 위치 갱신, 도착 자동 확인, 지연 시 먼저 알림 |
| 인증 코드는 브라우저 계산 | 서버 서명·검증, 기록 출처 확인 |
| 화면이 켜져 있어야 GPS 기록 | 앱 백그라운드 기록, 워치 앱 |
| 기기 연결은 일정 안내 | 애플 건강·헬스 커넥트(1단계 앱), 가민·삼성 헬스·Strava(2단계) |

## 5. 외부 자원

- 글꼴: Pretendard(SIL OFL), jsDelivr로 불러옴
